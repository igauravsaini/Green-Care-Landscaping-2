# Deploying Green Care Landscaping to Cloudflare Pages

This project is fully structured and pre-configured for **Cloudflare Pages** with:
- Next.js Static Export to `out/`
- Cloudflare Pages native Edge Functions in `functions/api/bookings.ts`
- Image optimization compatibility (`unoptimized: true`)
- Trailing slash URL routing for static CDN resolution
- Pre-configured `wrangler.toml` and `.nvmrc` (Node 20)

---

## ⚡ Option 1: Deploy via Cloudflare Dashboard (GitHub / GitLab)

1. Push your repository to **GitHub** or **GitLab**.
2. Go to the [Cloudflare Dashboard](https://dash.cloudflare.com/) > **Workers & Pages** > **Create application** > **Pages** > **Connect to Git**.
3. Select your repository (`Green Care Landscaping`).
4. In **Build Settings**, configure:
   - **Framework preset**: `None` or `Next.js (Static HTML Export)`
   - **Build command**: `npm run build`
   - **Build output directory**: `out`
   - **Root directory**: `/` (leave empty or default)
5. In **Environment Variables**, add:
   - `NODE_VERSION`: `20`
   - Any custom keys from `.env.example` (e.g. `NEXT_PUBLIC_GA_MEASUREMENT_ID`)
6. Click **Save and Deploy**.

Cloudflare Pages will automatically:
- Run `npm run build` to generate `out/`
- Mount `functions/api/bookings.ts` as a serverless edge endpoint at `/api/bookings`
- Deploy to your custom `*.pages.dev` domain with global edge caching and free SSL.

---

## 💻 Option 2: Deploy via Wrangler CLI (Direct Terminal)

If you have the Cloudflare Wrangler CLI installed:

### 1. Build the Static Project
```bash
npm run build
```

### 2. Deploy to Cloudflare Pages
```bash
npx wrangler pages deploy out --project-name=green-care-landscaping
```

Follow the terminal login prompt if it's your first time using Wrangler.

## 📁 Directory Structure for Cloudflare Pages

```text
├── functions/                    # Cloudflare Pages Edge Functions
│   └── api/
│       └── bookings.ts           # Handles GET, POST, PATCH for /api/bookings
├── out/                          # Generated by 'npm run build' (served by Cloudflare)
│   ├── index.html
│   ├── book/index.html
│   ├── admin/index.html
│   ├── services/index.html
│   ├── robots.txt
│   └── sitemap.xml
├── public/                       # Static public assets (images, icons)
├── src/                          # Application source code
│   ├── app/                      # Next.js App Router pages
│   ├── components/               # React UI components
│   ├── content/                  # Master site-config.ts
│   └── types/                    # Shared TypeScript types
├── next.config.ts                # Configured with output: "export"
├── wrangler.toml                 # Cloudflare Pages configuration
└── .nvmrc                        # Pin Node.js 20 runtime
```

## 🔗 Custom Domain & DNS Setup
Once deployed, in Cloudflare Pages dashboard:
1. Go to **Custom domains** tab.
2. Click **Set up a custom domain**.
3. Enter your domain (e.g., `greencarelandscaping.com` or `www.greencarelandscaping.com`).
4. Cloudflare automatically issues an SSL/TLS certificate and manages DNS routing.
